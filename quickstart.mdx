# Quickstart

Get up and running with the **CL40 World Ecosystem** in less than 5 minutes.

---

## Prerequisites

Before you begin, ensure you have the following ready:

- **Node.js 18+** or **C++20 Toolchain** (for core plugin extensions)
- A free **CL40 World Account** (`https://cl40.world`)
- An active API Key from **CL40 World Codes**
- A compatible OS (Linux, macOS, or Windows 11)

---

Configure

Initialize your environment and link your developer API credentials before first use:

```markdown
cl40-cli init
```

Run It

Start your local integration node to see it working and verify ecosystem connectivity:

```markdown
cl40-cli start
```

# Cookies & Local Storage Policy

The **CL40 World Ecosystem** uses essential cookies and local browser storage to maintain security, session state, and developer portal preferences.

---

## Types of Cookies We Use

1. **Essential Cookies:** Required for user authentication, API token authorization, and system security.
2. **Performance & Analytics:** Used to monitor latency, traffic distribution, and server health across global nodes (+210 countries).
3. **Preferences:** Stores theme settings (dark/light mode) and navigation state within the Mintlify documentation platform.

---

## Managing Cookies

You can disable or clear cookies at any time through your browser settings. Note that disabling essential cookies may impact authentication across **CL40 World** portals.
