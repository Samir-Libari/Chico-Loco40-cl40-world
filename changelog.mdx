  # Changelog

  Product updates, security advisories, and infrastructure improvements to the **CL40 World Ecosystem**.

  ---

  ## October 09, 2026

  ### 🛡️ Security Policy & Version Lifecycle

  - **Security Policy Published:** You can now report security vulnerabilities directly to the CL40 World engineering team at [only@cl40.world](mailto:only@cl40.world).
  - **Supported Versions:** Active security patches and maintenance updates are provided for versions **`5.1.x`**, **`5.0.x`**, and **`4.0.x`**.
  - **Deprecation Notice:** Versions earlier than **`4.0`** are officially End-of-Life (EOL) and no longer supported. Please upgrade your integration nodes to a supported release.

  ---

  ### 📦 Lifecycle Summary

  | Version Family | Support Status | Patch Level |
  | :-- | :-- | :-- |
  | **v5.1.x** | Active Support | Latest Release |
  | **v5.0.x** | Maintenance | Security Patches |
  | **v4.0.x** | LTS (Long Term Support) | Critical Fixes Only |
  | **\< v4.0** | Deprecated / EOL | Unsupported |
